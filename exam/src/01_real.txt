=== x01-pep | python enhancement proposals | real | https://peps.python.org/pep-0001/ | public domain (paraphrased) | ok
how a PEP actually happens (roughly, from memory of PEP 1): you float the idea on the Ideas category on discourse first and see if anyone cares. if it survives you write the draft PEP. needs a core dev to sponsor it unless you're one yourself. the PEP editors check the formatting and give it a number, then it goes in the peps repo. the real argument happens in the discussion thread and the draft gets revised from that. steering council makes the call eventually, they read the thread. a reference implementation should exist before it's marked Final. editors update the status header (Draft/Accepted/Final etc) when stuff happens.

q: What happens before the draft is written? | the idea is floated on Discourse | idea,draft
